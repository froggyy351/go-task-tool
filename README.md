# tt - タスク管理ツール

ボール（MyBall / OtherBall）でタスクを管理するシンプルなCLIツールです。

- **MyBall**: 自分がアクションを持っているタスク
- **OtherBall**: 相手にボールを渡して待っているタスク

## インストール

`tt.exe` を任意のフォルダに置き、そのフォルダにPATHを通してください。

```
C:\tools\tt.exe   ← 例
```

データファイル（`tt.txt`、`tt_done.txt`）は `tt.exe` と同じフォルダに自動生成されます。

## コマンド一覧

### タスクの追加

```
tt add "タスク名" -d 2026-06-20
```

MyBall にタスクを追加します。

```
tt add "タスク名" -d 2026-06-20 --to 田中
```

最初から OtherBall として登録します（依頼してすぐ待ち状態にする場合）。

**日付指定**:

| 形式 | 例 | 意味 |
|---|---|---|
| 絶対指定 | `-d 2026-06-20` | 2026年6月20日 |
| 相対指定 | `-d +3` | 今日から3日後 |

### 一覧表示

```
tt ls             # 全タスクを期限が近い順に表示
tt ls --my        # MyBall だけ表示
tt ls --other     # OtherBall だけ表示
tt ls --done      # 完了済みタスクを表示
```

引数なしで `tt` と打つだけでも一覧が表示されます。

**表示例:**
```
=== MyBall (2件) ===
  [1]   資料作成       2026-06-15  [!あと3日]
  [2]   見積もり提出   2026-06-30  あと18日

=== OtherBall (1件) ===
  [3]   レビュー依頼   2026-06-20  あと8日    担当: 田中
```

**期限の表示:**

| 表示 | 意味 |
|---|---|
| `[!期限切れ N日]` | 期限を過ぎている（赤色） |
| `[!今日]` | 今日が期限（赤色） |
| `[!あとN日]` | 3日以内 |
| `あとN日` | 4日以上 |

### ボールの移動

```
tt mv 3 田中      # ID:3 のボールを田中へ（OtherBall 化）
tt mv 3 me        # ID:3 を自分へ引き取り（MyBall 化）
```

### 完了・取り消し

```
tt done 3         # ID:3 を完了（tt_done.txt に退避）
tt undone 3       # 完了を取り消して現役に戻す
```

### 編集

```
tt edit 3 -d 2026-06-25           # 期限を変更
tt edit 3 -n "新しいタスク名"     # 名前を変更
tt edit 3 -d 2026-06-25 -n "名前" # 両方まとめて変更
```

### 削除

```
tt rm 3           # ID:3 を削除（確認プロンプトあり）
```

> 削除は物理削除です。完了ファイルへの退避はありません。

### その他

```
tt help           # コマンド一覧を表示
tt version        # バージョンを表示
```

## データファイル

| ファイル | 内容 |
|---|---|
| `tt.txt` | 現役タスク（TSV形式） |
| `tt_done.txt` | 完了済みタスク（TSV形式） |

どちらも `tt.exe` と同じフォルダに作成されます。
